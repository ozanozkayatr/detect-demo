# Personas

Static persona seed data for local demo analysis context.

Current starter personas:

- `experienced_boxer_coach`
  - 183 cm / 81 kg
  - 15 years of amateur/professional boxing experience
  - active coach with high training volume

- `beginner_amateur`
  - 168 cm / 62 kg
  - less than one year of boxing experience
  - lower-volume beginner training routine

These profiles are not user accounts. They are temporary demo personas that can
be selected before analysis so Gemini can tailor feedback to a likely athlete
context without changing the observable-only rules.
