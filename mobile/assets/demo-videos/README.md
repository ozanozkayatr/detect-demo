# Demo Videos

Put local sample boxing clips here when you want to test the mobile upload flow.

Suggested formats:

- `.mp4`
- `.mov`

Suggested naming:

- `bag-work-01.mp4`
- `mitts-01.mp4`
- `sparring-01.mov`

Notes:

- This folder is for local testing assets.
- Keep large personal videos out of git unless you explicitly want them versioned.
- On iOS Simulator, you can drag a file into the Photos app or import it there before testing upload.
